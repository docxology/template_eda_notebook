# Output Inventory — template_eda_notebook

> Every file in `output/` is **disposable but regeneratable**. This document is
> the contract between the pipeline and the manuscript: it inventories what the
> pipeline produces, which generator emits it, and which stage it lands in.

Paths in the table are relative to `projects/working/template_eda_notebook/`.

## File Inventory

| File | Role | Generated By | Pipeline Stage |
|------|------|--------------|----------------|
| `output/figures/height_histogram.png` | Height distribution | `src/eda/figures.py::histogram_data()` plotted in `scripts/eda_analysis.py` | 02 — Analysis |
| `output/figures/correlation_heatmap.png` | Feature correlation heatmap | `src/eda/figures.py::correlation_heatmap_data()` plotted in `scripts/eda_analysis.py` | 02 — Analysis |
| `output/figures/group_counts.png` | Rows per group | `src/eda/figures.py::group_count_data()` plotted in `scripts/eda_analysis.py` | 02 — Analysis |
| `output/data/summary_statistics.csv` | Per-column descriptive statistics | `src/eda/statistics.py::summary_statistics()` written by `scripts/eda_analysis.py` | 02 — Analysis |
| `output/reports/validation_report.json` | Pipeline validation summary | `infrastructure.validation.verify_output_integrity` | 04 — Validate |
| `output/pdf/*combined.pdf` | Working combined publication PDF | `infrastructure/rendering/pdf_renderer.py` via `scripts/pipeline/stage_03_render.py` | 03 — Render |
| `output/web/*.html` | HTML version of each section | `infrastructure/rendering` | 03 — Render |
| `output/logs/*.log` | Per-stage pipeline logs | `scripts/runner/execute_pipeline.py` | every stage |

Stage 05 copies the standalone registration to
`output/working/template_eda_notebook/` under the Template checkout. The
built-in exemplar uses `templates/template_eda_notebook` and copies to
`output/templates/template_eda_notebook/`.

## Adding a New Output File

1. Add the figure-data preparer in `src/eda/figures.py` (returns a dataclass of
   numbers; no matplotlib) with a test in `tests/test_figures.py`.
2. Plot it in `scripts/eda_analysis.py` and write the PNG under
   `output/figures/`.
3. Append a row to the table above naming the file, role, generator, and stage.
4. If the manuscript references it, add a `{#fig:label}` in the appropriate
   `docs/manuscript/*.md` section.
5. Re-run the analysis and confirm the new file appears.
